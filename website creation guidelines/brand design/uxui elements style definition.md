# Syntax UI Style Guide

*Minimal. Confident. Playfully precise.*

---

## Buttons

### Primary Button

* **Background**: Bright Yellow (`#fff351`)
* **Text**: Deep Purple (`#060f38`)
* **Font**: Clash Display Medium, uppercase or sentence case
* **Padding**: `12px 24px`
* **Border Radius**: `8px`
* **Effect**: Subtle shadow or scale-in on hover
* **Usage**: Main CTA – “Jetzt buchen”, “Loslegen”, “Weiter”

### Secondary Button

* **Variants**:

  * Filled: Deep Purple (`#060f38`) with white text
  * Soft: Pastel background (e.g. `#e4ddff`) with dark text
  * Outlined: White background, dark border (`#060f38`)
* **Hover**: Invert or apply slight tint
* **Usage**: Secondary actions, minimal flows, or form submission

---

## Badges / Tags

* **Text**: “Neu”, “Live”, “100% gefördert” etc.
* **Shape**: Rounded pill (`6px radius`)
* **Font**: Clash Grotesk Medium, 14px
* **Colors**: Use semantic colors from palette (green, purple, pink, etc.)
* **Variants**:

  * Solid fill
  * Subtle background
  * Outline only

Use for: Labeling modules, courses, offers

---

## Cards

* **Padding**: `32px`

* **Border Radius**: `16px`

* **Shadow**: Soft elevation (e.g., `0 8px 24px rgba(0,0,0,0.05)`)

* **Layout**:

  * Subtitle (uppercase, small)
  * Bold headline (Clash Display)
  * Body text (Grotesk, Regular)
  * Actions (buttons aligned bottom or inline)

* **Color Themes**: Use light pastel backgrounds (Green `#dcfae4`, Yellow `#fffab9`, Blue `#e8f1fa`, Purple `#e4ddff`)

* **Interaction**: Hover highlight or slight elevation increase

Use for: Feature blocks, course intros, product teasers

---

## Typography

### Headlines

* **Font**: Clash Display
* **Weights**: Medium / Semibold
* **Letter spacing**: +3%
* **Case**: Sentence case or stylized lowercase
* **Sizes**: Scaled using golden ratio (1.618× base size)

### Body Text

* **Font**: Clash Grotesk
* **Weight**: Regular
* **Letter spacing**: +5%
* **Size**: 16–20px
* **Line Height**: 1.6–1.75
* **Color**: Deep Purple (`#060f38`) or muted (`#6a6f88`)

---

## Text Inputs

* **Font**: Clash Grotesk
* **Padding**: `12px 20px`
* **Border**: `1px solid #cdcfd7`
* **Border Radius**: `8px`
* **Background**: White
* **Focus State**: Border `#7656fd` (Syntax Purple), subtle glow
* **Placeholder**: Muted (`#9b9faf`)

Use for: Forms, sign-ups, booking fields

---

## Links

* **Font**: Clash Grotesk
* **Color**: Deep Purple (`#060f38`)
* **Underline**: On hover or persistent inline
* **Context**: Use inline or within blocks (e.g. “Ich bin ein *Link* in einem Text”)

---

## Visual Identity Summary

* **Shapes**: Rounded corners on all elements
* **Spacing**: Generous whitespace, modular blocks
* **Color Mood**: Bright, soft, accessible. Base on deep purple and expressive accents
* **Visual Rhythm**: Clean grid, modular cards, clarity through contrast
* **Tone**: Self-confident, smart, a little playful — never overly corporate
