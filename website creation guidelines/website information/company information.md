# 🎓 Syntax Institut

**Moderne Tech-Ausbildung für den Quereinstieg in Web, App und Cloud – modular, anerkannt & förderfähig**

---

## 🔧 Bildungsmodell: Modular und individuell

Das Syntax Institut bietet vollständig modulare Tech-Weiterbildungen an, die für den Bildungsgutschein (BGS) zugelassen sind.
Statt starrer Kurse folgt das Institut einem flexiblen **Lernpfadmodell** – bestehend aus **Kompetenzbausteinen**, die einzeln oder kombiniert belegt werden können.

### Lernpfad-Highlights:

* **Einzelbuchung möglich**: Jedes Modul ist separat förderfähig.
* **Individuell kombinierbar**: z. B. Einstieg mit Webdesign, danach App- oder DevOps-Vertiefung.
* **Empfohlene Lernpfade**: Die Kurse Web, App und Cloud bestehen aus sorgfältig kuratierten Modulreihenfolgen.
* **Flexibler Einstieg**: Auch ein Start bei Modul 3 ist möglich (z. B. bei Vorerfahrung).
* **Anerkannte Abschlüsse**: Viele Module enden mit IHK-Zertifikaten.

---

## 🌐 Lernpfad 1: **Web Development**

Ziel: Einstieg in moderne Webentwicklung mit Frontend- und Backend-Kompetenzen.
Abschluss mit mehreren IHK-Zertifikaten.

| **Modul**                        | **Dauer**  | **Inhalte**                                                                         | **Abschluss**                                      |
| -------------------------------- | ---------- | ----------------------------------------------------------------------------------- | -------------------------------------------------- |
| **Modul 1**: Produktdesign       | 4 Monate   | UI/UX Design, Designprinzipien, Figma & Framer, Projektmanagement, Produktstrategie | 💼 *Junior Product Designer (IHK)*                 |
| **Modul 2**: Web-Grundlagen      | 3 Monate   | HTML & CSS, Bootstrap, JavaScript & TypeScript, Publishing                          | 🌐 Interaktive Website                             |
| **Modul 3**: Frontend-Frameworks | 2,5 Monate | React, Next.js, Angular/Vue (Einblick), Tailwind CSS, Strapi, Deployment            | 💻 *Junior Web Developer (IHK)* *(nach Modul 2+3)* |
| **Modul 4**: Spezialisierung     | 2,5 Monate | Node.js, Express.js, Authentifizierung, Datenbanken, Performance & Automation       | 🧠 *Web Development Specialist (IHK)*              |

👥 **Zusätzliche Angebote über alle Module hinweg:**

* Bewerbungstraining & Karrierecoaching
* Soft Skills: Kommunikation, Motivation, Resilienz
* Zertifikatsvorbereitung: Google UX, Scrum Master, ECDL, W3Schools

## 📱 Lernpfad 2: **App Development**

Ziel: Entwicklung nativer iOS- und Android-Apps – von Design bis App Store.
Abschluss mit zwei IHK-Zertifikaten möglich.

| **Modul**                            | **Dauer**  | **Inhalte**                                                                                   | **Abschluss**                    |
| ------------------------------------ | ---------- | --------------------------------------------------------------------------------------------- | -------------------------------- |
| **Modul 1**: UX/UI Design            | 4 Monate   | App-Designprinzipien, User Flows, Wireframes & Prototyping in Figma, Design-Transfer in Xcode | 🎨 Design-Prototyp               |
| **Modul 2**: Programmiergrundlagen   | 3 Monate   | Swift-Grundlagen, Xcode-Einführung, Logik & Syntax, Kontrollstrukturen, App-Grundgerüste      | 👨‍💻 iOS-Playground-App         |
| **Modul 3**: iOS App-Entwicklung     | 2,5 Monate | SwiftUI, Datenhandling, Navigation, Animationen, Core Features, SwiftData                     | 🍏 *App Developer iOS (IHK)*     |
| **Modul 4**: Android App-Entwicklung | 2,5 Monate | Jetpack Compose, Kotlin, Architektur, Android Studio, Persistenz, Gerätefunktionen            | 🤖 *App Developer Android (IHK)* |

⚙️ Kombinierbar mit Web- oder Cloud-Modulen – z. B. für Fullstack- oder DevOps-Karrierepfade.

## ☁️ Lernpfad 3: **Linux & Cloud Engineering (DevOps-orientiert)**

Ziel: Einstieg in Systemadministration, DevOps-Prozesse & Cloud-Infrastrukturen.
Praxisnah, ideal auch für technisch orientierte Quereinsteiger\:innen.

| **Modul**                                    | **Dauer** | **Inhalte**                                                                    | **Abschluss**                     |
| -------------------------------------------- | --------- | ------------------------------------------------------------------------------ | --------------------------------- |
| **Modul 1**: Grundlagen IT & Betriebssysteme | 3 Monate  | IT-Netzwerke, Linux-Grundlagen, IT-Sicherheit, Datenschutz, digitale Werkzeuge | 💡 IT-Basiskompetenz              |
| **Modul 2**: Linux, Python & Cloud Basics    | 3 Monate  | Shell, Python-Programmierung, Einführung AWS/Azure, Container (Docker)         | 🐧 Linux Essentials Vorbereitung  |
| **Modul 3**: Webtechnologien & Admin-Wissen  | 3 Monate  | HTML/CSS, GitHub, Webserver, Deployment, Monitoring, Fehleranalyse             | 🌐 Technische Umsetzungskompetenz |
| **Modul 4**: DevOps & Cloud                  | 3 Monate  | CI/CD mit Jenkins, Automatisierung mit Ansible, Terraform, Cloud Deployment    | ☁️ *Cloud IT Administrator (IHK)* |

🧪 Optional: Praxisprojekt + Bewerbungssprints + Prüfungsvorbereitung
